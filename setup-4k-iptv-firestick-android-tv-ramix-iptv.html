Hardware Requirements

Before you begin, ensure your devices meet these minimum specifications:

  1. Firestick 4K or Fire TV Stick 4K Max – supports HDMI 2.0 and HDR.
  2. Android TV – any TV box or smart TV running Android 7.0 (Nougat) or newer, with at least 2 GB RAM.
  3. Stable internet connection: minimum 25 Mbps download for smooth 4K playback.
  4. HDMI‑2.0 cable (if using an external TV box).

Step‑by‑Step Setup on Amazon Firestick

1. Prepare Your Firestick

  1. Connect the Firestick to your TV’s HDMI‑2.0 port and power it on.
  2. Navigate to Settings > My Fire TV > About and note the device version (should be 6.2.0 or later).
  3. If you haven’t already, enable Apps from Unknown Sources under Settings > My Fire TV > Developer Options.

2. Install a Compatible IPTV Player

We recommend IPTV Smarters Pro or TiviMate. The steps below use IPTV Smarters Pro:

  1. Open the Search icon on the home screen.
  2. Type IPTV Smarters Pro and select the app from the results.
  3. Choose Get and wait for the installation to finish.

3. Add the Ramix IPTV Playlist

  1. Launch IPTV Smarters Pro.
  2. Select Add New User → Enter Details Manually.
  3. Enter a name (e.g., Ramix 4K).
  4. For Username and Password, use the credentials provided in your Ramix purchase email.
  5. Paste the M3U URL (e.g., https://ramixiptv4k.store/playlist.m3u) into the Playlist URL field.
  6. Tap Add User. The app will validate the link and load the channel list.

4. Optimize for 4K Playback

  • Go to Settings > Player Settings > Video Quality and select 4K (3840×2160) if available.
  • Enable Hardware Decoding to reduce buffering.
  • Set Buffer Size to 8 seconds for a balance between latency and stability.

Step‑by‑Step Setup on Android TV

1. Install an IPTV Player

  1. Open the Google Play Store on your Android TV.
  2. Search for IPTV Smarters Pro (or TiviMate if you prefer).
  3. Select Install and wait for the download to complete.

2. Configure the Ramix Playlist

  1. Open the installed app and choose Add New User.
  2. Select Enter Details Manually.
  3. Fill in the same fields as described for Firestick: user name, username, password, and the M3U URL.
  4. Tap Save. The channel list will appear within seconds.

3. Adjust Video Settings for 4K

  • Navigate to Settings > Player Settings > Video Quality and set it to 4K.
  • Turn on HDR support if your TV model supports it.
  • Enable Auto‑Play Next Episode for series binge‑watching.

Troubleshooting Common Issues

Buffering or Stuttering

  • Check bandwidth: Run a speed test on the same network. If you’re below 25 Mbps, consider a wired Ethernet connection.
  • Reduce buffer size: In the player settings, lower the buffer to 4 seconds.
  • Switch servers: Ramix provides multiple server URLs in the account dashboard. Try a different one.

No Channels Appear

  • Verify the M3U URL is typed correctly—no extra spaces.
  • Make sure your subscription is active; expired accounts return an empty playlist.
  • Restart the IPTV app and, if needed, reboot the device.

Audio Desynchronization

  • Go to Player Settings > Audio Sync and adjust the delay in 0.5‑second increments.
  • Update the app to the latest version; older builds may have codec issues.
